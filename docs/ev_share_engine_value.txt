§8-3 EV 보급률별 엔진 가치 — 현재 · 10% · 15%
================================================================================
작성   2026-11-16
무대   추석 2026-09-25 UP · 10시드 · 같은 세계에서 EV 보급률만 바꿔 돌렸다
       (`--ev-share` · scenario_id 에 `__ev04` / `__ev10` 꼬리표가 붙는다)
바닥   MNL 운전자 선택 모형 θ=0.05 · w=1.0 · ASC 없음 = **엔진 없는 평상시**
비용   체류 + 이탈 비용 + 포기 전 대기 (`runner.social_cost_h`, 세 항)


0. ★ 발표에 쓸 세 문장
--------------------------------------------------------------------------------
    "현재 수준(EV 3.7%)에서는 엔진이 **17.5%** 를 줄입니다.
     EV 가 **10%** 가 되면 **28.5%**,
     **15%** 가 되면 **41.9%** 를 줄입니다."

  전부 **엔진이 없을 때(평상시) 대비**이고, 10시드 전부에서 이긴다.

### 3.7% 이 어디서 나왔나 — 이제 숫자로 말할 수 있다

#167 환경부 충전이력을 전 운영사로 환산하면 (상행 원장 44기 / DB 129기):

    평시     686건/일 (원장)  →  약 2,012건/일
    연휴 피크 (2/17 설날)  930건/일  →  약 **2,727건/일**

모델이 EV 10% 에서 7,436건/일이므로 역산하면 **약 2.7%(평시) ~ 3.7%(연휴 피크)**.
그래서 10%·15% 는 **미래 시나리오**다 — 지금까지 "⚠ 실측 비율 아님" 이라고만
적었는데, 이제 "현재 약 3.7%" 라고 기준점을 댈 수 있다.

1-B. ★ S2 를 같이 놓으면 — **사다리는 병목이 생겨야 갈라진다** (2026-11-18)
--------------------------------------------------------------------------------
  EV      MNL 바닥       S2        S4      S2 개선    S4 개선   S4−S2   병목(S0)
  ────── ─────────── ───────── ───────── ────────── ────────── ─────── ────────
  3.7%        362h      299h      299h     17.44%     17.46%   +0.02%p    0.0
  5%          503h      404h      404h     19.61%     19.58%   −0.03%p    0.0
  10%       1,192h      848h      852h     28.83%     28.53%   **−0.30%p**  0.0
  15%       2,757h    1,726h    1,603h     37.41%   **41.85%** **+4.44%p**  9.2

★★ **EV 10% 아래에서는 S2 와 S4 가 사실상 같다.** 10% 에서는 S4 가 오히려 미세하게
   나쁘다 (851.5 vs 848.0h). 병목이 0칸이라 **재배정으로 옮길 쏠림이 없고**, S4 가
   더 가진 것(경로 재질의 · 재예약 비용 · `hard_lock_min`)이 값을 못 낸다.

   병목이 9.2칸 생기는 **EV 15% 에서만 S4 가 S2 를 4.44%p 앞선다.** 즉 사다리의
   윗칸은 "더 똑똑해서" 이기는 것이 아니라 **쏠림이 있을 때만** 이긴다.

   ⚠ 발표에서 "단계가 올라갈수록 좋아진다" 고 말하면 10% 칸에서 걸린다.
     EV 15% 무대(발표 본 무대)에서만 사다리를 보이거나, 이 표를 그대로 보이고
     **"병목이 없으면 갈라지지 않는다"** 를 결과로 말하는 것이 정직하다.

   이탈로 봐도 같다 — S2·S4 의 이탈이 5% 1.4/1.4대 · 10% 3.0/2.8대로 붙어 있고,
   15% 에서만 6.9 → 4.2대로 갈라진다.


2. ★★ 둘로 갈라야 정직하다 — "안내" 와 "최적화"
--------------------------------------------------------------------------------
총 개선은 **성격이 다른 두 몫**의 합이다. 섞어 말하면 질문에서 걸린다.

  EV      ├ 안내 (MNL→S0)        └ 최적화 (S0→S4)       총
  ────── ────────────────────── ────────────────────── ─────────
  3.7%    **14.5%p** [13.6,15.4]    3.0%p [ 2.0, 3.9]    17.5%
  10%     **24.1%p** [22.9,25.4]    4.4%p [ 3.9, 4.8]    28.5%
  15%       25.6%p   [23.6,27.5]  **16.3%p** [14.4,18.1]  41.9%

  **안내 (MNL → S0)**
    "운전자가 혼자 고를 때" 와 "화면에 지금 상태를 보여 줄 때" 의 차이다.
    줄이 없어도 생긴다 — 더 빠른 충전기를 고르게 되기 때문이다.
    EV 10% 에서 포화된다 (24.1 → 25.6%p).

  **최적화 (S0 → S4)**
    화면을 보고도 생기는 쏠림을 엔진이 **나눠 주는** 몫이다.
    3.0 → 4.4 → **16.3%p**. 병목이 생기는 15% 에서 **네 배로 뛴다.**

★ 이게 §8-3 의 핵심이다.

    "엔진의 **절반 이상은 지금도 가치가 있습니다** — 현재 수준에서도 17.5%.
     다만 그건 대부분 **'어디가 빈지 알려 주는'** 몫입니다.
     **진짜 최적화의 값은 병목이 생길 때 나타납니다** — EV 15% 에서
     3.0%p 가 16.3%p 로, **다섯 배**가 됩니다."

  ⚠ 3.7% · 10% 에서는 병목 슬롯이 **0.0** 이다. "줄이 없는데 엔진이 왜 필요한가"
    에 대한 답이 위의 '안내' 몫이고, 그걸 '최적화' 라고 부르면 안 된다.


3. 질문 대비
--------------------------------------------------------------------------------
### Q. "지금은 EV 가 3.7% 인데, 10%·15% 는 언제 오나요?"

    "저희가 답할 수 있는 건 **'그때가 되면 이만큼'** 까지입니다. 시점은
     보급 정책의 문제라 저희 모형 밖입니다. 다만 **3.7% 인 지금도 17.5%**
     가 나오므로, 기다릴 이유는 없습니다."

### Q. "EV 10% 에서는 왜 4단계가 3단계보다 나쁜가요?"

  EV 10%:  S3 **29.03%** [28.06, 30.00]  ·  S4 28.53% [27.57, 29.49]

    "병목 슬롯이 0 이기 때문입니다. 줄이 없으면 5분마다 재배정하는 것이
     이득 없이 흔들기만 합니다. **15% 가 되면 뒤집힙니다** — S3 37.8%,
     S4 41.9%, 10시드 전부에서."

  → 숨기지 말 것. 이건 "엔진의 가치는 병목이 생기는 순간 나타난다" 의
    가장 깔끔한 증거다.

### Q. "3.7% 에서 17.5% 면 생각보다 큰데요?"

    "맞습니다. 다만 그 17.5% 중 **14.5%p 는 '안내'**, 즉 지금 어디가
     빈지 알려 주기만 해도 생기는 몫입니다. 최적화 알고리즘이 추가로
     만드는 값은 3.0%p 입니다. 그 3.0%p 가 EV 15% 에서 16.3%p 가 됩니다."

  ★ `run_mnl_world.py --ev-share` 는 `run_chuseok_ladder.py --ev-share` 와
    **글자 하나까지 같은 꼬리표**(`__ev10`)를 만든다. 다르면 MNL 바닥과 사다리
    칸이 서로 다른 scenario_id 를 갖게 되어 "같은 세계" 가 아니게 된다 (#59).

  ⚠ 0.037 의 꼬리표는 `__ev04` 다 (반올림). 3.7% 인데 이름이 04 다 — 헷갈리면
    `runs/.../manifest.json` 의 `demand_label` 을 볼 것.

⚠ EV 15% 는 config 기본값이라 꼬리표가 없다. `--ev-share 0.15` 로 다시 돌리면
  물리는 같고 run_id 만 달라져 같은 일을 두 번 한다 — 기존 run 을 읽는다.


5. 이전 숫자와 다른 이유 (기록)
--------------------------------------------------------------------------------
`docs/final_presentation_actions.txt` 에 적힌 **"EV 10% 5.78% · EV 15% 21.75%"**
는 **S0 기준**이다 (S0 → S4). 이 문서는 **MNL 바닥 기준**이다.

    S0 기준     EV10%  903.8 → 851.5  =  5.78%
    MNL 기준    EV10% 1,192.1 → 851.5 = 28.53%

발표의 §7 결론(41.9%)이 MNL 기준이므로 **§8-3 도 MNL 기준으로 맞춘다.**
섞어 쓰면 "같은 무대인데 숫자가 두 개" 가 되어 반드시 걸린다.
