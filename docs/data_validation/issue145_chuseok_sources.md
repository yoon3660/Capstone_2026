## 검산 기록

- 09-23~28 TCS64 전국 정리 원장 5,858,118행, 일별 매트릭스 1,225,824행. 검사한 일자·시간·기종점·차종 키의 중복 및 대수 결측·음수는 0이었다. 이는 정리 원장의 구조 검사이며 OD 시간 셀이 모두 관측됐음을 뜻하지 않는다.
- 경부선 공통 OD에서 09-24 TCS35와 TCS39 일합은 일치했다. TCS64 대 TCS39 일합 비교 WAPE는 09-24 64.71%, 09-25 0.12%, 09-26 0.13%, 09-27 3.03%다. 원장 수정과 시간대 보간은 적용하지 않았다.
- 평시 03-06~15 VDS 교통량 31,680행 중 4,392행 결측, TCS OD 17,220행 중 대수 결측 0. 검사 키 중복 및 음수 0.
- 충전 세션 비율만으로 EV 통행 비중을 따로 식별하려면 운영사 범위 외에 충전 확률과 통행당 세션 수가 필요하다. EV 비율 확정은 별도 근거가 필요하다.

## 후속 수집과 충전 자료의 판정

- **시각 정의:** 공급전력, 세션, 물리 점유를 별도 관측량으로 둔다. 원본의 종료−시작은 우선 기록된 세션 경과시간으로 이름을 붙인다. 별도 충전시간 열은 제공기관이 정의를 확인하기 전까지 원래 값으로 보관한다. 차이가 난다는 이유만으로 충전 후 유휴로 배정하지 않는다. 전력 공급시간은 계량·충전 상태 이력, 커넥터 점유는 연결·해제 또는 다음 차량이 사용할 수 있게 된 상태 이력으로 확인한다. 주차면 물리 점유는 센서나 차량 입출차 기록이 별도로 필요할 수 있다. OCPP에서는 거래의 시작·종료 조건을 설정할 수 있고, 연결 중에도 전력 공급이 중단될 수 있다.
- **점유 보정:** 정확한 경계 이벤트가 없으면 세션 경과시간은 관측 범위를 명시한 대용치로만 사용한다. 차이가 큰 행은 운영사·장비·오류 코드별로 분리하고, 시간대 경계와 장시간 행을 검산한다. 같은 커넥터의 세션이 겹치면 중복 또는 오류 후보로 표시한다. 점유시간의 보정값을 직접 확정하는 근거는 아직 없다.
- **운영사 범위:** 한국환경공단 공개 API의 상태·마지막 충전 시각은 최신 상태 조회에 해당한다. 현재 조회로 9월 모든 세션을 복원할 수 없다. 워터의 공개 15,608건은 2026-02-14~18 전국 49곳·241기의 단일 운영사 표본이다. 추석 세션 수나 경부선 전체 사업자 커버리지로 집계하지 않는다. 무공해차 통합누리집의 정보 전송 안내에 명시된 법 시행일도 2026-11-11로, 9월 전수 수집을 보장하는 근거가 되지 않는다.
- **추석 공급:** 휴게소·방향별 공식 시설 명부에 충전기 고유 식별자와 운영사, 개통·중단·철거 일시, 임시 설비 운영 기간을 결합해야 한다. 중복 커넥터와 동시 충전 가능 슬롯도 구분해야 한다. 10/26 목록과 추석 시기 일부 구간 공개 수치를 결합해도 9월 전수 재구성에는 부족하다.
- **원자료 확보 요청에 넣을 항목:** 09-23~28 KST에 걸친 비식별 세션 ID, 운영사·충전소·충전기·커넥터 ID, 연결/해제·전력 시작/종료·거래 시작/종료 시각, 종료 사유, 충전량 단위, 유효일 있는 충전기 목록. 세션이 날짜 경계를 넘는 경우도 포함하며, 운영사별 자료 기간과 누락 구간을 함께 확인한다. 제공기관에 요청을 발송하지는 않았다.

### 9월 충전기 공급 근거 재확인

- #64 종료 보고서는 2026-09-18 환경공단 API 응답 3페이지에서 경부선 충전기 등록 후보 282개를 매핑했다고 기록한다. 보고서가 가리키는 원본은 data/raw/highway_chargers_20260918_125202_all/page_*.json이다. 현재 체크아웃과 검색한 Documents 경로에서는 해당 원본을 찾지 못했다. 215기는 2월 설 모델용 선정값이며 9월 목록과 구분한다.
- 2026-09-26 공개된 evplace의 경부 상행 표는 휴게소 16곳, 표의 합계 142기, 300kW 이상 37기를 보여준다. 휴게소별 등록 수와 출력의 동시기 대조 근거다. 개별 ID와 연휴 시간별 운영 여부는 확인되지 않았다. 해당 사이트가 언급한 30분 상태 이력의 공개 페이지는 최근 8일로 제한된다.
- 9/18 원본이 복구되면 충전소·충전기 ID, 운영사, 휴게소 방향, 출력으로 9/26 공표 집계 및 10/26 목록과 대조할 수 있다. 추가·누락과 ID 변경은 유효일이 있는 개통·중단·철거 및 장애 이력으로 분리한다. 출처별 합계는 모집단이 달라 단순 차감하지 않는다.

### 공개 과거 이력 조사 및 수집 마감

9/18 13:44:50 환경공단 원본 3페이지(2,092행, 충전소 ID와 충전기 ID 조합 중복 0)를 확인했다. 기존 휴게소 이름·방향·좌표 기준의 경부선 등록 공급 후보는 하행 19곳 153기, 상행 16곳 129기다. 추석 직전 공급 대용치로 채택한다. 9/26 민간 상행 집계 142기와는 모집단이 다를 수 있다.

공공데이터포털 환경공단 API는 최신 명부 및 최근 1~10분의 상태 변경을 제공한다. 차지인포와 공공 충전소 표준 자료에서 대상 날짜별 원장을 확인하지 못했다.
