## 이번 #134 범위에서 이미 확보한 근거

- **VDS 구조 및 결측**: 63,360 키 정합, 54,523 동시 관측 / 8,825 동시 결측 / 12 한쪽만 결측.
- **진입·진출**: DOWN 2/13, UP 2/17 저장본 재계산 일치, 1km 초과 고유 공백 각 9곳.
- **CTM 구조·재검증**: 792셀 기본 DB 적재·마스터 validate PASS. DOWN2/13 속도 MAPE14.37% PASS, 정체 Recall0.00 FAIL — 이는 **#58과 같은 측정의 재현**이고 새 증거가 아니다. #134가 새로 더한 것은 **민감도 제거 조합**(최고 Recall0.2833, 기준0.50 미달)뿐이며 그 산출 코드는 아직 저장소에 없다. **기본 UE는 `travel_time=fixed`**.
- **차량/충전 코드**: DB `validate` 이상 없음, `test_charging.py` 28개 테스트 성공 표시. 현재 기본 DB↔YAML 차량5·곡선20·온도9행 필드 일치 PASS. #18·#25·#27은 내부·보정 기준 검증이며 독립 실측 일반화는 미확정.
- **통합 감사 재실행**: `audit_issue134_readonly.py` 로컬 완료. VDS 63,360×2 구조, 대표일 entry/exit, DB 마스터, #64 매핑·20회 QA 메타 재확인. 재시뮬레이션/전 이벤트 감사는 아님.
  - **2026-10-15: 이 스크립트를 저장소에 커밋했다.** 문서값을 기대값으로 박아 두고 다시 계산하는 회귀 테스트이며, **다른 PC에서 94개 검사 전부 일치**했다. 즉 `LOCAL_NEW` 항목 중 이 94개는 더 이상 한 사람의 세션 출력에 의존하지 않는다.
  - CTM 본표(MAPE14.37·RMSE14.39·편의+4.92·정체60/적중0·Recall0.0000)도 **기존 스크립트·기존 런으로 재현 확인**: `scripts/validate_ctm_speed.py --run seollal_2026_down_base__ctm__UE__p100__s0007`. 출력 자리수를 문서에 맞춰 고쳤다. **민감도 조합만 여전히 재현 불가.**
- **시간열·에너지 별도 근거**: 전국 기간 시작 188,123행에서 원본 `충전시간`과 종료−시작 60초초과 차이39,327행. 경부선 UP김천 277,468행 원본31분11초 vs 경과2,404.183분. 경부선 11,405건 충전량 원본 평균22.093(단위 확인 전 kWh 단정 금지). 기존 #129·#131 주장에 반증가능성 기록.
- **충전 공급/외적 증거**: #64에서 **과거 시설 근거 조사·282후보 판정과 BASE215 공급 선정·적용 완료**. #134에서 215 ID 매핑·20회 QA 메타 확인, 비피크 18개 입력 54/54 SHA 일치 PASS. **외적 모델 정확도 평가를 위한 실제 거래 운영사 모집단 정합성**은 미입증이며 공급 선정을 재조사하는 과제로 분류하지 않는다.
