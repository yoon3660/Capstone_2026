## 민간 충전기 이력 추가 확보 문의 현황

## 품질 검사와 집계 기준

대상 4,480건에서 `(충전소ID, 충전기ID, 시작, 종료, 충전시간, 충전량)` 완전 중복 0, 종료 결측 0, 음수/결측 에너지 0이다. 영(0) kWh는 33건이고 시작 기록 집계에는 유지했다. 시작=종료인 0분·0kWh 행 2건은 시작 건수에는 유지하되 경과시간 분포에서는 제외했다. 따라서 '성공 충전' 4,480건이 아니라 **기록된 충전 시작 4,480건**이다. 거래 상태·성공 여부 필드는 없다.

원본 충전시간 0분 5건, 충전시간이 경과시간보다 긴 행 96건(모두 차이 1분 이내), 경과시간 120분 초과 8건, 최대 752.58분이다. 동일 장비ID에서 세션 시간 중첩은 0건이다. 장시간 기록을 근거 없이 제거하지 않았다. 경과시간 이상이 물리적 장기 점유인지 기록 지연인지 불명확하다.

검증 기간 안에 시작하고 9/28 이후 끝나는 10건도 시작 건수·세션 전체 분포에 포함했다. 시간대별 **시작** 집계와 기간 안으로 잘라낸 점유율은 서로 다르며, 이번에는 점유율을 만들지 않았다. 완전 중복 여부는 경부선 대상 기간에 대해 검사했으며 전국 전 행의 모든 필드 품질을 완료했다고 주장하지 않는다.

## 실측↔UE 대조 가능 범위

현재 공유된 #147 자료는 `gap_tables_down/up.txt`, `s4_paired_comparison.csv`의 종합 지표다. 날짜·휴게소·운영사·충전기·시작/종료·kWh가 있는 **추석 UE charge_event 원장과 차량 OD 원장은 로컬 runs/ 및 공유 첨부에서 찾지 못했다.** 설 UE 이벤트로 대신하지 않았고 신규 UE도 실행하지 않았다. #147은 공통 시드 14개·기본 EV 5% 가정을 보고하지만 비교할 개별 run 설정/이벤트가 없어 특정 시드를 임의로 골라 실측과 비교하지 않았다.

| 요청 지표 | 이번 결과 | 필요한 후속 입력 |
|---|---|---|
| 세션 건수 Bias·WAPE | N/A, 모델 이벤트 부재 및 ALL↔ME 모집단 불일치 | 날짜별 UE ALL과 동일 관측 ID 집합의 이벤트 |

## 점유시간 모델링에 사용할 근거

이번 값은 경부선의 실제 기록된 세션 시간·에너지 분포에 관한 근거다. 순수 충전시간과 종료−시작을 따로 보존했다. 두 값 차이를 자동으로 기기 조작·충전 후 유휴시간이라고 해석하면 안 된다. 연결·해제 이벤트가 없으므로 물리 점유시간도 직접 검증되지 않았다.

원본 충전시간은 정확히 40분인 행이 261건이며 P90도 40분이다. 장비 운영 제한·기록 방식에 의한 집중일 수 있어 무조건 하나의 로그정규/감마 분포로 맞추기보다 출력·장비·운영 조건별 경험분포를 먼저 점검해야 한다. 이번 작업에서는 분포를 모델에 적용하거나 ±10% 목표를 통과했다고 판정하지 않았다.
