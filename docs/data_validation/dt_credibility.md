## 2. 실제 모델 경로에 따른 평가 단위

### A. 현재 기본 설 연휴 YAML

- `travel_time: fixed` → **CTM 속도 필드가 아닌 고정 속도**. 사용자 기본 DB의 `cell=792`과 함께, 지금 기본 실행을 “검증된 CTM 기반 혼잡 예측”으로 지칭하지 않는다.
- `od_profile: null` → TCS 조건부 목적지 샘플링 **비활성**. 진입·진출 프로파일 기반 위험률로 목적지를 추정한다.
- `ev_share: 0.05`, `departure_soc: holiday`, `habit_soc: 0.0`, `target_soc_cap: 0.8`, **양방향 `ev_count_method: fixed`**, `layers: []` → 충전 대수·충전량·체류시간을 좌우하는 주요 가정. #53 Poisson 기능이 구현돼 있어도 **기본 시나리오에서는 시간대별 EV 대수가 고정**된다. **정확도 PASS 값으로 취급하지 않는다.**
- 보급 확대/혼잡 YAML은 각각 **EV 10%/15%와 기회충전 20%를 함께 적용**한다. 기본값 대비 KPI 차이는 두 가정의 결합 결과이며, EV 비중 하나의 단독 인과효과가 아니다. 모두 `travel_time=fixed`라서 `congested` 파일명이 CTM 정체 검증을 뜻하지 않는다.
- 기본 `evdt.db` 활성 충전기 **282기** (DOWN153 / UP129) → 2026년 설 실제 공급으로 확정한 수치가 아니다.

### B. #64 BASE215 격리 실험

- 별도 가상 공급 **215슬롯** (DOWN112 / UP103; ME95 / NONME120), 기본 DB와 분리.
- 20개 날짜×방향 24시간 독립 실행; 전날 대기·점유 이월 없음.
- **환경부 제공** 이력 29곳 11,405건 대비 모의 **ME라 표시된** 8,413건. 제공기관≠운영사 ME일 수 있어 모집단 등가가 미입증.
- 기존 #64 수치: 시작 총량 편향 −26.23%, 휴게소×일 WAPE 78.49%, 점유시간 5,141.3h vs 1,779.6h. **조건부 기술통계**일 뿐 실제 충전 혼잡의 PASS/FAIL 판정 아님.
- 6개 미관측 휴게소는 **N/A**, 실측 충전 0회가 아니다.

### 4.2 확인된 현상과 인과 원인 후보의 경계

**CTM:** 82.636km, 135.801km 두 경계의 *추정* 진출량을 함께 제거한 민감도 실행에서는 속도 MAPE가 **13.33%**, 정체 Recall이 **0.2833(17/60)**으로 변했지만 **오경보 56개**가 발생했다. 즉 **진출입 추정 입력에 정체 예측이 민감하다**는 사실은 확인했다. 그러나 해당 가상 제거가 실제 IC/JCT 진출량을 반영한다는 증거는 없으며, **진출입 추정이 정체 미재현의 유일한 원인이라고 결론 낼 수 없다**. #24의 차로 원본 대조·파라미터 기준 선정도 완료 사실로 유지한다.

**OD·EV:** #61의 TCS 내부 OD는 검증된 **내부 통행 관측**이고, #62의 시간대 OD는 **명시한 조건에서 선정·평가한 추정 모델**이다. 기본 위험률 방식과 TCS OD 대안의 거리/구간량 상충은 확인됐으나, 특정 방법을 전체 경부선 EV 경로의 참값으로 확정하지 않는다. EV 5%·명절 진입 SoC의 **현장 대표성 미확인**을 #55·#82의 분포 선정·간접 검증 실패로 다시 표기하지 않는다.

**충전:** #64에서 **설 이전 시설 근거에 따른 공급 분류와 BASE215 결정은 완료**했다. 미확정인 것은 *동등 거래 모집단에서 충전 이용·점유 오차를 평가할 수 있는가*이며, 공급 재조사가 곧 전제조건인 것은 아니다. 또한 #134의 `종료시각−시작시각`과 원본 별도 열 `충전시간`은 동일한 관측량이라고 전제하면 안 된다. 두 값의 차이를 **곧 충전 후 유휴 또는 로그 오류**로 판정할 근거는 없다. #112의 그룹 이용률 근접 결과는 해당 조건의 성과로 보존하고 #64 실행으로 소급하지 않는다.

### 4.3 판정 보류의 이유와 재판정에 필요한 최소 근거

- **F-01(CTM 정체 FAIL):** 선행 FAIL은 유지하며, 같은 Conzone×시간 표본에서 정체 위치·시각·오경보를 재검사한다. 독립적인 램프 진출입·병목 차로 및 용량 근거가 확보되어야 원인 후보를 확정할 수 있다. **새 검사 없이 원인 확정 또는 PASS로 바꾸지 않는다.**
- **F-03/F-04(수요):** #61/#62/#55/#82 완료 결과는 유지한다. 기본 위험률과 OD 활성화 모델의 **입력 모집단·기간·설정**을 나눠 같은 조건에서 통행거리와 구간 통과량을 함께 비교한다. #67 EV 비율 대표성은 별도 출처와 분모가 필요하다.
- **F-02/F-06(충전):** #64의 BASE215 결론을 그대로 사용한다. 환경부 제공 로그의 **운영사 거래 범위**, 기록 `충전시간`과 세션 시각차의 의미·충전량 단위, 장비별 동등 표본을 확인할 수 있을 때만 외적 정확도 판정을 진행한다. **현장 대기시간 자체는 충전 거래 로그로 대체 불가**이며 직접 대응 관측이 필요하다.
- **미래 예측·최적화:** 예측 시점에 실제로 사용 가능했던 입력만으로 미래 ETA·정체를 생성하고, **예측 이후 실측 결과와 분리 평가**해야 한다. 실제 정책 효과는 동등 조건의 현장·준실험 근거 없이 단정하지 않는다.

**종합:** 이번 #134의 미달·보류는 모두 같은 의미의 '미완료'가 아니다. **CTM 정체는 기준 미달이 확인된 FAIL**, **OD·충전은 실측과의 불일치 또는 조건부 검증 결과와 미분리 원인이 공존**, **현장 대기·미래 예측은 직접 비교 근거가 부족해 UNKNOWN**이다. 이는 기존 티켓의 범위 내 완료 판정과 동시에 성립한다. 상세 수치와 검사 계보는 [`validation_report.md`](validation_report.md), 후속 업무 범위는 [`followup_issues.md`](followup_issues.md)를 따른다.
