# #134 — 디지털 트윈 기능별 신뢰성 평가

> 2026-10-15 갱신. 기본 시나리오와 #64 격리 실험을 구분한다. #134에서는 CTM을 별도 재검증했지만, 기본 UE 전체를 CTM 조건으로 다시 실행하지 않았다.

## 2. 실제 모델 경로에 따른 평가 단위

### A. 현재 기본 설 연휴 YAML

- `travel_time: fixed` → 기본 시나리오는 고정 속도로 이동시간을 계산한다. 현재 DB에 CTM 셀 792개가 적재돼 있지만, 기본 실행에서 CTM이 자동 활성화되지는 않는다.
- `od_profile: null` → TCS 조건부 목적지 샘플링 **비활성**. 진입·진출 프로파일 기반 위험률로 목적지를 추정한다.
- `ev_share: 0.05`, `departure_soc: holiday`, `habit_soc: 0.0`, `target_soc_cap: 0.8` → 충전 대수·충전량·체류시간을 좌우하는 주요 가정. **정확도 PASS 값으로 취급하지 않는다.**
- 기본 `evdt.db` 활성 충전기 **282기** (DOWN153 / UP129) → 2026년 설 실제 공급으로 확정한 수치가 아니다.

### B. #64 BASE215 격리 실험

- 별도 가상 공급 **215슬롯** (DOWN112 / UP103; ME95 / NONME120), 기본 DB와 분리.
- 20개 날짜×방향 24시간 독립 실행; 전날 대기·점유 이월 없음.
- **환경부 제공** 이력 29곳 11,405건 대비 모의 **ME라 표시된** 8,413건. 제공기관≠운영사 ME일 수 있어 모집단 등가가 미입증.
- 기존 #64 수치: 시작 총량 편향 −26.23%, 휴게소×일 WAPE 78.49%, 점유시간 5,141.3h vs 1,779.6h. **조건부 기술통계**일 뿐 실제 충전 혼잡의 PASS/FAIL 판정 아님.
- 6개 미관측 휴게소는 **N/A**, 실측 충전 0회가 아니다.

## 3. 주요 불확실성의 전파 경로

| 미확정 입력 | 확산되는 결과 | 현재 상태 |
|---|---|---|
| EV 비중 5% | 생성 EV 대수 → 충전 필요 대수 → 대기/큐·배정 | 잠정값, 독립 현장 비율 검증 필요 |
| 출발 SoC holiday | 1회/복수 충전 필요 여부 → 도달성·후보·점유 | 분포 및 33% 바닥은 행태 가정 |
| OD/중간 진입·진출 | 각 차량의 주행거리·충전 필요 → 특정 휴게소 선택 쏠림 | 현 진출 위험률과 내부 TCS OD 상충, 공간 공백 존재 |

| CTM 정체 재현 실패 | CTM 사용 시 도착시간 추정 → 대기 예측 → 정책 입력에 영향 가능 | #58 및 #134 하행 실측 재현 FAIL. 다만 #64는 `fixed` 실행이므로 #64 오차의 직접 원인으로 단정할 수 없음 |

## 4. 보고·발표에서 쓸 수 있는 표현

**가능한 표현**

> “도로와 VDS의 주요 키·공간 구조, 중간 진출입 데이터 재생성, 충전시간 계산 로직은 내부 검증했다. CTM은 평균 속도 지표는 통과했지만 설 연휴 정체 재현율이 0으로 미달했다. 충전기·EV 행동 및 충전 혼잡의 외적 적합성은 아직 조건부 또는 미검증이다.”

**피해야 하는 표현**

- “경부선 명절 실측 정체를 정확히 재현했다.”
- “2월 실제 충전기 215기를 모두 확인했다.” / “기본 DB의 282기가 모두 2월 가동했다.”
- “환경부 제공 기록 11,405건은 ME 운영사 거래만이다.”
- “충전시간 유닛테스트를 통과했으므로 실제 대기시간도 검증됐다.”
- “현재 기본 시나리오는 실측 OD·CTM 기반이다.”
- “모의 최적화 개선량은 실제 운전자에게 그대로 발생한다.”

## 5. 이번 #134 보고의 결론

**DT의 입력·구조·계산 로직에 대해 부분적으로 신뢰 가능한 기반은 확보됐지만, 현실 혼잡의 재현/예측 및 최적화 효과까지 검증한 단계는 아니다.** 특히 CTM 정체 재현의 선행 FAIL, OD/EV 수요·SoC의 가정, 실제 충전기 모집단과 충전 점유시간 불일치가 다음 단계의 핵심이다. 검증 실패·미확인을 숨기지 않고 명시하면 #134의 데이터 감사 목적에 부합한다.
