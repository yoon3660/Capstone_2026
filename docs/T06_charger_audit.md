## 2. 휴게소 구성

현재 시뮬레이션 대상은 총 **35개 휴게소**이다.

- **DOWN (서울 → 부산): 19개**
- **UP (부산 → 서울): 16개**

환경부 데이터와 한국도로공사 데이터의 휴게소명을 정규화한 뒤

```text
(휴게소명, 방향)
```

기준으로 매칭하였다.

운영사명이 포함되어 매칭되지 않는 일부 데이터는 명시적인 alias로 처리하였다.

```python
STATION_NAME_ALIASES = {
    "워터경주휴게소": "경주휴게소",
    "워터칠곡휴게소": "칠곡휴게소",
    "서울하이패스센터(입구)": "서울하이패스센터쉼터",
}
```

### 2.1 이름에 방향이 없는 시설

방향은 휴게소명의 `(부산)` / `(서울)` 표기로 정하고, 이름에 방향이 없으면
도로공사 휴게소 기준정보 API(`restinfo/hiwaySvarInfoList`)의 공식 상·하행 구분
(`gudClssNm`)을 쓴다. 두 API는 `stdRestCd`(= `svarCd`)로 연결된다.

이름에 방향이 있는 34곳과 공식 구분을 비교해 **34곳 모두 일치**하는 것을 확인했고,
앞으로 둘이 다르면 적재가 멈춘다 (`apply_official_directions`).

환경부 충전소명에 방향이 없을 때(`옥천만남 휴게소`)는 경부선에 그 이름의 휴게소가
**하나뿐일 때만** 매칭한다. 칠곡처럼 상·하행이 모두 있는 이름은 붙이지 않는다.
좌표 교차검증(2 km)은 똑같이 적용된다 (`resolve_charger_key`).

좌표로 도로의 어느 쪽인지 판별하는 방법도 시험했으나, 방향을 아는 34곳 중
15곳이 틀려서 쓰지 않는다. 도로공사 IC 좌표가 본선이 아니라 요금소 위치라
기준선이 수백 m씩 흔들린다.

## 3. offset_km

`offset_km`은 방향별 기점에서 **노선을 따라간** 누적거리다.

- DOWN 기점: 양재IC (`0010I00045`)
- UP 기점: 구서IC (`0010I00001`)
- 총연장 L (구서IC ~ 양재IC): 약 391 km → `corridor.length_km`

도로공사 휴게소·IC API에는 이정(기점거리) 필드가 없다 (좌표·코드·이름만 제공).
그래서 두 기점 + 경부선 IC/JCT + 휴게소를 노선 순서로 잇고 인접 점 사이
거리를 누적한다 (`route_mileposts`). 상·하행은 한 노선을 공유하므로
UP offset = m, DOWN offset = L − m 이다.

처음 버전은 기점과 휴게소 사이 직선거리를 썼는데, 구서IC 기준으로
직선 307 km / 노선 약 391 km 라 뒤로 갈수록 간격이 압축됐다
(§7.2 충전 필요 판단에 그대로 들어가 수요가 전반부로 쏠리는 가짜 신호가 된다).

노선 순서는 "기점 직선거리"로 정하면 안 된다. 영천~경산~동대구 구간은
구서IC를 중심으로 호를 그려서 직선거리가 74.1 → 75.8 → 75.2 → 79.6 km 로
오르내리고, 그 순서로 이으면 상행 칠곡 이후가 약 60 km 부풀려진다.
두 기점을 고정하고 가장 먼 점부터 경로를 가장 적게 늘리는 자리에 끼우는
방식(farthest insertion)으로 순서를 정한다.

도로공사 IC 목록에는 중복(영천·김천·추풍령·구서)과 좌표가 어긋난 행이 있어,
경로를 3 km 넘게 늘리는 IC는 버린다.

남은 오차: 선분 근사라 실제 도로보다 몇 % 짧다. 오차가 구간 전체에 고르게
퍼져 있어 휴게소 간 간격의 비율은 유지된다.

## 4. DB 적재

DB 적재 스크립트:

```bash
python scripts/load_chargers.py
```

최종 적재 결과:

| 항목 | 결과 |
|---|---:|
| station | 35개 |
| charger group | 103개 |
| physical charger | 282기 |

`charger` 한 행은 동일한 출력 및 커넥터 타입을 가진 충전기 여러 기를 나타낼 수 있으므로  
실제 충전기 수는 다음과 같이 계산한다.

```text
SUM(charger.n_units)
```

## 5. 충전기 대수 검증

검증 스크립트:

```bash
python scripts/audit_charger_counts.py
```

환경부 raw 데이터의 고유한

```text
(statId, chgerId)
```

조합을 실제 충전기 1기로 계산하여 DB와 비교하였다.

최종 결과:

```text
현재 DB: 282
환경부 공개데이터: 282
차이: 0
```

(2026-09-18 재수집본 기준. 2026-09-17 수집본은 33개 휴게소 / 276기 / 100그룹이었다.)

**35개 휴게소 모두 개별 충전기 대수도 일치하였다.**

초기에는 268기만 매칭되었으나 다음 데이터가 휴게소명 앞의 운영사명으로 인해 누락되어 있었다.

- `워터 경주휴게소 부산방향`: 5기
- `워터 칠곡휴게소 서울방향`: 3기

alias 적용 후 최종 **276기**가 정상적으로 매칭되었다.
