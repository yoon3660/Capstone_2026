# S1 — 예약 원장을 보고 고르는 운전자 (사다리 두 번째 칸)

> 한 줄: **원장은 평균을 못 줄인다. 대신 최악을 자른다.**
> 최대 대기 577.7 → 169.0분, 못 기다려 나간 차 193.1 → 24.8대.

코드: `engine/reservation.py` · `engine/s1.py` · 실행: `run_ue.py --stage S1`

---

## 1. S0 와 딱 두 가지가 다르다

나머지는 **전부 같다** — 차량 집합, 휴게소·충전기, 통행시간, 기온 계수, 충전량 규칙,
큐 규칙, 이탈 비용. `S1Policy` 는 `S0Policy` 를 물려받아 도달 가능성·충전량·이탈 판정을
**같은 코드**로 쓴다.

| | S0 | S1 |
|---|---|---|
| 비용 | **지금 화면**의 대기 + 내 충전시간 | **내가 도착할 시각**의 체류 (원장) |
| 묻는 법 | 전원이 같은 스냅샷을 보고 동시에 | **한 대 쓰고 다음 차가 본다** |

### 두 번째가 핵심이다

#59 가 S0 가 지는 이유를 숫자로 보였다 — 원인은 "정보가 낡아서" 가 아니라
**낡은 정보를 모두가 같이 보고 같이 움직여서**다.

> 같은 5분 안에 결정한 차 전원이 같은 화면 → 같은 계산 → 같은 곳.
> 40분 뒤 도착하면 앞에 30대가 서 있다.

**원장을 읽기만 하고 안 쓰면 S0 와 똑같다.** 전원이 같은 원장을 보고 또 몰린다.
그래서 `book()` 이 다음 차를 묻기 **전에** 들어간다.

### 최소 재현

`tests/test_s1.py::test_s1_splits_where_s0_sends_everyone_to_the_same_place`

> 5대가 1분 간격, A·B 모두 충전기 1기, 출발 시점에 둘 다 대기 0.
> **S0 는 전원 A (총 대기 77.0분) · S1 은 3대 A · 2대 B (31.3분).**

## 2. 한 칸 앞을 본다 — 그리고 왜 주행시간은 답이 아닌가

처음 구현은 비용이 **체류시간뿐**이었다. 그랬더니 **줄이 짧다는 이유로 가까운 곳을
고르고, 조금만 채우고, 또 섰다** — 2회 이상 정차가 S0 547 → S1 629 로 늘고 평균 대기가
S0 보다 나빠졌다.

**"주행시간을 더하자" 는 효과가 없다.**

> 코리도에서는 **주행시간이 상수다.** 어느 휴게소를 고르든 목적지까지 총 거리는 같다.
> `travel(여기→X) + travel(X→목적지) = travel(여기→목적지)` 라서 비교에서 상쇄된다.

**선택을 가르는 것은 "또 서야 하는가" 하나다.** 그래서 충전하고도 목적지에 못 가면
**다음 정차의 체류를 원장에서 읽어 더한다.**

| | 몇 칸을 보나 |
|---|---|
| UE | **계획 전체** (max_stops 까지 열거) |
| **S1** | **한 칸** |
| S2 | 그 너머 — 예측 |

고친 뒤 2회 이상 정차가 **629 → 379**.

### 조심한 것 둘

- **두 번째 정차는 원장에 안 쓴다.** 아직 고르지도 않은 정차를 예약하면 다른 차가
  **있지도 않은 줄**을 본다. 묻기만 한다
- **닿는 곳이 없으면 0 을 돌려준다.** 큰 수를 돌려주면 "못 가는 곳" 과 "줄이 긴 곳" 이
  같은 값으로 섞인다. 막다른 길은 `max_stops` 와 이탈 판정이 따로 잡는다

## 3. 결과 — 상행 균형 시나리오, 세 단계 공통 시드 14개

| | UE | S0 | **S1** |
|---|---:|---:|---:|
| 진입 EV | 38,603 | 38,603 | 38,603 |
| 충전 필요 EV | 7,251.6 | 7,251.6 | 7,251.6 |
| 평균 대기 | 6.3 | **38.5** | 39.3분 |
| P95 대기 | 42.4 | 131.2 | **115.6분** |
| **최대 대기** | 91.3 | **577.7** | **169.0분** |
| **최악 휴게소 평균** | 40.8 | **163.6** | **78.4분** |
| 병목 슬롯 | 30.0 | 93.5 | **133.1칸** |
| **이탈: 줄이 길어서** | 41.1 | **193.1** | **24.8대** |

> 시드가 14개인 이유: UE 가 20시드 중 6개에서 수렴하지 않았다. 세 단계가 **모두
> 수렴한 시드만** 쓴다 — 아니면 다른 차 집합을 비교하게 된다 (#59).

### ⚠ 평균 대기만 보면 S0 가 이긴다. 그게 함정이다

```
S0  평균 38.5분   이탈 238.9대
S1  평균 39.3분   이탈  55.5대
```

**S0 는 239대를 코리도 밖으로 내보내고 얻은 숫자다.** 나간 차는 충전기를 안 쓰니
남은 사람의 평균이 좋아진다. **그 사람들은 2시간을 따로 쓴다.**

> 병원이 중환자를 안 받으면 평균 회복률이 올라간다. 그걸 "치료를 잘했다" 고 하지
> 않는다.

### 총 사회적 비용 — 이탈을 세면 뒤집힌다

```
총비용 = 총 체류(시간) + 이탈한 차 × 이탈 비용(120분)
```

| | 총 체류 | 이탈 비용 | **합계** | UE 대비 |
|---|---:|---:|---:|---:|
| UE | 2,473.0h | 84.6h | **2,557.6h** | — |
| S0 | 7,038.3h | **477.7h** | **7,516.1h** | +193.9% |
| **S1** | 7,179.8h | **111.0h** | **7,290.8h** | **+185.1%** |

**S1 이 S0 보다 225시간(3%) 싸다.** 체류는 142h 더 쓰고 **이탈 비용을 367h 줄여서**
총량이 역전된다.

`scripts/compare_stages3.py` 가 이 줄을 항상 같이 찍는다 — 안 세면 **"내보내면 이긴다"**
가 된다.

### 정직하게 — 병목은 늘었다

```
병목 슬롯   S0 93.5 → S1 133.1칸
```

나갔을 차를 붙잡아 두니 30분 넘게 막히는 칸이 늘어난다.

> **"최악은 사라졌지만 적당히 나쁜 상태는 늘었다"** 가 정확한 표현이다.

## 4. UE 와 비교하면 안 되는 이유, 그리고 봐야 하는 이유

**S1 은 UE 를 이길 수 없다.** 종류가 다르다.

| | 무엇을 고르나 | 누가 무엇을 아나 |
|---|---|---|
| **UE** | 목적지까지의 **계획 전체** | 전원이 **서로의 최종 선택**을 안다 (반복 균형) |
| **S1** | **다음 한 곳** (+한 칸 앞) | 각자 **자기 앞까지의 선택**만 안다 |

UE 는 **기준선이지 운영 방식이 아니다.** 현실에서 모든 운전자가 서로의 최종 선택을 알
수는 없다. 계산도 50배 걸린다 — **14시드에 UE 약 80분, S1 1.6분.**

> 그래서 S1 의 185% 는 "실패" 가 아니라 **"한 번 훑어서 얻을 수 있는 몫"** 이다.
> 그리고 1.6분이라는 것은 Δt 5분 안에 **실제로 돌릴 수 있다**는 뜻이다 (#77).

## 5. 설계 규칙 — 두 번 걸렸다

**시뮬레이터는 원장이 무엇인지 모른다.** `run_corridor(ledger=...)` 는 받아서 `WorldView`
에 넣을 뿐 들여다보지 않는다. 알면 "어느 단계가 도는지" 아는 셈이고 설계 규칙 2 가 깨진다.

**큐 규칙은 원장을 거친다.** `s1.py` 가 `queue_rule` 을 직접 임포트했더니
`test_queue_rule_has_at_most_two_callers` 가 잡았다. 호출자가 늘면 규칙이 갈라진다.

**원장은 S0 에 안 준다.** 줘도 안 보지만, 주면 "무엇이 달라졌나" 가 흐려진다.
안 주면 S1 은 `require_ledger()` 에서 **그 자리에서 터진다.**

## 6. 테스트를 세 번 잘못 짰다

**S0 와 S1 이 정확히 일치**하게 나와서 원장이 고장 난 줄 알았다. 멀쩡했다.

| 잘못 | 왜 안 보였나 |
|---|---|
| `max_stops=3` | 차가 A·B **둘 다 경유** — 선택이 아니라 경로였다 |
| `soc0=0.45` | **B 가 사정권 밖** — "몰린다" 가 아니라 "갈 데가 하나" |

> 두 번째가 특히 위험하다. **"쏠림" 과 "선택지가 없음" 은 숫자로 똑같이 보인다.**
> `_ev` 에 하한 계산(0.6)을 주석으로 박아 뒀다.
