# SP5 천장 재설계 (1/2) — MNL 세계를 만들고 고정 참여율에서 천장값을 잰다

부모: SP5 천장 재설계 · 선행: #118(완전예측 롤링), #147(추석 재실행), #162(추석 충전이력) · 관련: #167(S0 vs UE 재현성)

## 요약

지금 사다리의 바닥(S0)과 참고 천장(UE)은 둘 다 결정적 규칙이라 현실 운전자를 대표하지 못한다. 기존 완전예측 27.5%도 **설 상행 시나리오에서 UE를 천장으로 둔 격차 축소율**이지, 현실 세계에서 얻을 수 있는 천장값이 아니다(`docs/ladder.md`).

이 티켓에서는 두 가지를 한다.

1. **다항 로짓(MNL)으로 운전자의 휴게소 선택을 확률적으로 만든 세계**를 구축한다.
2. 그 세계에서 **참여율 p만큼의 차량을 완전정보 Oracle로 최적화했을 때 비용이 어디까지 내려가는지(천장값 J\*(p))**를 지표로 낸다.

MNL 자체는 천장이 아니다. 천장은 MNL 세계 위에서 Oracle이 만드는 값이다.

## 크기

약 12시간 (구현 6 · 보정 3 · 실행·정리 3)

## 세계 정의

```
참여자 (u_i < p)   : 엔진/Oracle 이 고른 휴게소로 간다 (DESIGN §2.3, 완전 준수)
비참여자 (u_i ≥ p) : MNL 로 스스로 고른다
    V_is = −(T_charge_is + β_w · W_screen_s),   이탈 V = −escape_cost_min_i
    선택 = argmax(V_is + ε_is / θ),  ε ~ Gumbel, (seed, ev_id, s) 로 고정
u_i ~ U(0,1) : (seed, ev_id) 해시로 차량마다 한 번 고정 — 새 난수 흐름
```

**참여율은 휴게소 선택(`decide()`)만 가른다.** 충전 필요 여부, 충전량(목표 SoC 0.8 상한, habit_soc), 기회 충전, 이탈 비용은 지금처럼 모든 스테이지가 같은 값을 쓴다.

- u_i를 고정하므로 참여자 집합이 중첩된다(p=0.3 ⊂ 0.6 ⊂ 0.9). 같은 시드의 엔진과 Oracle은 같은 참여자를 상대한다.
- θ→∞이면 MNL은 S0와 같아진다. 그래서 기존 바닥과 연속성이 있다.

> **DESIGN §2.3과 다른 점**: 설계 문서는 비참여자를 "UE 방식"으로 둔다. 하지만 UE는 하루 전체를 미리 푸는 계산이라 Δt 루프에서 일부 차량에만 적용할 수 없다. 또 §1.2는 UE를 "현실"이라 부르지 말라고 한다. 그래서 비참여자는 MNL로 둔다. **팀 합의가 필요하다.**

## 지표

| 칸 | 참여자 | 비참여자 |
|---|---|---|
| 바닥 J_MNL | (p=0) | MNL |
| 엔진 J_Sk(p) | S1~S4 | MNL |
| **천장값 J\*(p)** | 완전정보 Oracle (`PERFECT_ROLLING` 롤링 고정점, 1회차 오라클 = MNL 바닥 런) | MNL |

- 총비용(h) = 총 체류 + 이탈 대수 × 120분 (기존 정의 그대로)
- **p는 값 하나로 고정한다.** 참여율 스윕(30/60/90%)과 동적 참여율은 담당 티켓의 범위이며, 이 티켓은 p만 바꿔 넣으면 되는 연결부(`ParticipationPolicy`)를 제공한다
- 보고할 것: 고정 p에서의 천장값, 천장 절감률 `(J_MNL − J*)/J_MNL`, 엔진 격차 축소율 `(J_MNL − J_Sk)/(J_MNL − J*)`
- p=1이면 비참여자가 없어 MNL은 바닥(분모)에만 들어간다. MNL이 천장값에 영향을 주려면 p<1이어야 한다
- 이탈을 맞추고 비교한다 (`docs/compare_rule.md`, ±35%)

> 이 천장값은 **완전정보 벤치마크**다. 최적성을 보장하지 않으므로 "상한"이라 부르지 않는다(DESIGN §1.2). 진짜 사후 최적해(MILP, §8.3)는 범위 밖이다.

## 완료조건

- [ ] 참여율 래퍼 구현. p=1에서 기존 엔진 런과 같고, p=0이면 엔진이 한 번도 호출되지 않으며, 참여자 집합이 중첩된다

- [ ] 실행 시나리오와 EV 비중을 결과에 명시한다 (추석 5%는 혼잡이 거의 없다 — #147)

## 하지 않는 것

- 설 독립 검증 (θ 고정 후 일반화) → (2/2)
- 참여율 스윕(30/60/90%)·동적 참여율 p(t) → 참여율 담당 티켓
- 추천 수락 모델(수락 보너스 κ) → (2/2) 또는 후속
- 대기·점유시간 리모델링과의 동시 변경 (MNL 효과를 분리하기 위해 120분 이탈 규칙과 점유 모형은 고정)
- 사후 최적해 MILP (DESIGN §8.3)
- 요금·편의시설 효용 (데이터 없음)
