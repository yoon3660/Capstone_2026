## 2-A. 환경부(ME)·민간/비ME 충전 기록 구성 방식 — 자료 출처 및 증거 수준 구분

**#64의 핵심 조사 방식은 두 종류의 충전기를 같은 방식으로 관측했다고 가정하지 않고, 출처가 다른 자료 흐름을 분리하여 구성한 것이다.** 여기서 `환경부 제공 이력`은 원자료 **제공기관**을 가리키며, 원본 속 개별 거래가 `busiId=ME` 사업자 전용이었다는 사실까지 뜻하지 않는다. 반대로 `NONME`는 **모델에 붙인 운영사 분류**이며 그 이벤트는 관측 거래가 아닌 UE 출력이다.

| 구분 | 환경부 제공 이력 · ME 모델 대응 | 민간/KP 등 비ME · NONME 모델 대응 |
|---|---|---|
| 2026년 2월 직접 확보한 자료 | 충전 시작·종료 시각, 충전량, 표시 충전기 ID가 있는 **개별 세션 원본 XLSX** | **전체 사업자의 개별 2월 거래·상태 이력은 미확보**. 일부 민간 사업자 발표의 제한적 관측만 확보 |

**구성 단계 요약**

1. **ME 쪽 실측 시계열 생성:** `data/raw/sp3_64/20260306_2026년2월_환경부_충전기_충전이력_상세내역.xlsx`를 원본으로 보존. 설 10일 동안 시작한 충전 세션을 휴게소·방향·날짜·시간에 묶고, 종료시각과 기간 경계를 이용해 점유시간도 계산했다. `sp3_64_charging_hourly.csv`, `sp3_64_10day_utilization_by_station.csv` 등 가공 경로가 기존 조사에 남아 있다.
2. **비ME 쪽 역사적 공급 근거 구성:** 과거 개소·운영·현장·조달 자료를 2026년 9월 API의 사업자/휴게소 후보와 연결하여 채택·제외 근거를 작성했다. 이에 따라 **ME 95 + 비ME 120 = BASE215**를 선택했고, 실제 2월 개별 가동 기수와는 구분했다. 워터의 제한적 관측은 별도 표본으로 보존했다.
3. **UE 이벤트를 운영사별로 따로 생성·집계:** `model_unit_to_operator.csv`의 가상 충전기→운영사 구분을 사용해 `ue_charge_events_by_operator.csv`의 각 이벤트를 `ME`와 `NONME`로 구분했다. `sp3_64_validate_20day_base215.py`는 이 구분에 따라 휴게소×일/시간 시작 및 점유를 각각 집계한다. 여기서 **ME/NONME 이벤트는 둘 다 시뮬레이션 결과**이며, 2월 직접 실측은 원본 XLSX에서 나온 관측 값뿐이다.
4. **비교 가능 범위 명시:** 관측 11,405건을 모델 ME 8,413건과 비교한 WAPE 78.49%는 **비교 집합 정합이 미입증된 조건부 진단치**다. 모델 전체(운영사 합계) 또는 NONME 모의 이벤트를 관측 11,405건과 동일 모집단의 참값처럼 비교하지 않는다. 6개 미관측 휴게소의 민간 이용은 0으로 추정하지 않는다.

**실측과 추정의 명명 규칙:** 보고서·발표에서는 `① 환경부 제공 개별 충전 이력(실측)`, `② 민간/비ME 과거 설치·운영 증빙(공급 근거)`, `③ 워터 등 민간 사업자 부분 실측`, `④ UE ME/NONME 모의 충전 이력`을 구분한다. **민간 전체 10일 실측 충전 이력을 별도로 구축했다고 주장하지 않는다.** 실제 개별 민간 거래 자료가 추후 확보되면 별도 출처·기간·사업자별 원장으로 추가 검증할 필요가 있다.

## 5. 검증지표·통과 기준 **제안안** (사후 임계값 변경 금지)

### 5-1. 필수 비교 가능성 게이트 — 통과 전에는 성능 합격·불합격을 채점하지 않음

1. 실측과 모델은 같은 **2026-02 일자, 29개 관측소, 충전 ‘시작’ 시각**으로 비교한다.
2. **실측 거래의 사업자 범위와 모델 `ME` 대리 범위 동등성이 확인**돼야 외적 정확도 판정이 가능하다. 현재 **미확인**.
3. 실제 충전 소별 미관측 `N/A`는 0으로 대체하지 않고, **관측이 0인 시간 셀**은 MAPE에서만 제외한다.
4. 충전기 공급값이 `실측 당시 실제 물리 가동수`가 아닌 **BASE215 proxy**임을 모든 결과표/그림에 명시한다.
5. 자료 오류·중복 의심·전일 또는 익일 이벤트 이월을 규칙에 따라 동일하게 처리한다.

**현 상태:** 내부 산술 QA **통과**, 외적 현실 적합성 성능 판정 **보류**. 게이트 #2 미충족이므로 아래 잠정 임계값을 적용해 '실패'라고 선언하지 않는다.

### 5-2. 수치 지표 정의

- `WAPE=100×Σ|모델−관측|/Σ관측` (관측 셀만; 관측 0도 오차 분자에 포함).
- `MAPE=100×mean(|모델−관측|/관측)` (관측 >0인 셀만; `mape_n` 함께 표기).
- `Bias=100×(Σ모델−Σ관측)/Σ관측` (과대·과소 상쇄 가능, 공간 오차를 대신할 수 없음).
- `MAE/RMSE`: 휴게소×일 또는 휴게소×시간 해상도를 반드시 표시한다.
- `Peak-hour error`: 같은 날·방향의 관측 시작 최다 시각 − 모델 시작 최다 시각, 동률이면 더 이른 시각을 기준으로 고정한다.
- `Busy-hour WAPE`: 각 시간 셀에서 실제 충전 중이었던 분/시간 합계에 대한 오차. 실제 물리 기수 미확정이므로 이것을 장비 이용률 정확도라고 부르면 안 된다.

### 5-3. **연구용 잠정 목표(아직 합의·승인되지 않음)**

| 지표 | 잠정 목표 제안 | 이유·사용 제한 |
|---|---|---|
| 휴게소×일 시작 건수 | 관측 ≥20건 지점의 `abs(모델−실측)/실측 ≤30%` | 작은 분모에 MAPE가 요동치므로 저수요 지점은 건수 차이를 기록. 허용치 30%는 연구용 제안이며 승인 아님 |
| 날짜×방향 피크시각 | 관측−모델 **±1시간 이내** | 같은 운영사 모집단과 시간표가 확보된 경우에만 성능 판정. 현재는 진단 4/20일 |
| 전체 WAPE/MAPE | **기록 필수, 합격선은 팀에서 확정** | 다른 집계 해상도·사업자 필터를 섞어 임계치 설정 금지 |
| 충전시간 P50/P90 / 충전량 P50/P90 | 동일 기기·사업자 표본 확보 후 비교 | 현재는 조건부 기술통계; 오차만으로 합격·불합격 판정 금지 |
| 실제 대기시간 | **정량 판정 불가** | 같은 시간대의 실제 대기시간 표본을 확보하지 못함 |

**이 표의 30%, ±1시간은 이미 통과했다고 주장하는 결과가 아니라, 사전에 승인받아야 할 제안**이다. 2026-10-13 작성 시점에 이미 계산 결과를 확인한 이후의 제안이므로 독립 사전등록 기준이나 외부 검증 성공처럼 포장해서도 안 된다.
