## 3. ★ #112 의 "판정 보류" 를 풀 재료가 생겼다

#112 는 충전 이용률이 실측의 1/3 이라는 것까지 재고 **판정 보류**로 끝냈다 — 대조할
실측 충전 로그가 없었기 때문이다. **이제 있다.**

### 점유시간 부족을 두 갈래로 쪼갠다

세션 체류는 곱으로 분해된다.

    체류(분) = 세션 에너지(kWh) ÷ 유효출력(kW) × 60

우리 런(UE, 상행)에서 잰 모델 쪽:

| | 값 |
|---|---:|
| 에너지 / 세션 | **17.0 kWh** |
| 충전시간 / 세션 | **13.7분** |
| **유효출력** | **74 kW** (명목 235kW 의 **32%**) |
| soc_in → soc_out | 0.38 → 0.59 (**swing 0.21**) |

> 유효출력이 명목의 32% 인 것은 **저온계수 0.61** 과 **충전곡선 테이퍼** 때문이다.
> 모델 13.7분은 팀원의 모델 12.69분과 같은 영역이다 (시나리오는 다르다).

**실측 27.05분이 어디서 오는지가 질문이다.**

| 만약 | 뜻 |
|---|---|
| 유효출력이 모델과 같다(74kW)면 | 실측 세션은 **33.5 kWh** — 모델의 **2.0배**. SoC swing **0.42** vs 모델 0.21 |
| 에너지가 모델과 같다(17kWh)면 | 실측 유효출력이 **37 kW** — 모델의 절반 |

**둘은 고쳐야 할 곳이 완전히 다르다.**

- 에너지가 원인 → **충전량 규칙**(`ChargeAmount`)이 "목적지까지 갈 만큼만" 넣는 것.
  실측 swing 0.42 는 **"80%까지 채운다"** 에 가깝다 (0.37 + 0.42 ≈ 0.79) — DC 급속에서
  흔한 행동이고, 우리 `target_soc_cap` 0.8 은 **기회 충전에만** 쓰이고 있다
- 출력이 원인 → **저온계수·충전곡선**이 실제보다 빠르게 잡혀 있는 것

### ★ 답이 나왔다 — 그리고 **우리가 이미 #112 에서 찾았던 것**이다

`openpyxl` 을 넣어 보고서 23개 시트를 읽고, 우리 충전 곡선으로 계산했다.

#### 우리 곡선으로 두 시나리오를 계산하면

| 시나리오 | 소요 | 세션당 |
|---|---:|---:|
| 모델 규칙 (0.38 → 0.59, "목적지까지 갈 만큼") | **11.1분** | 17 kWh |
| **80%까지 (0.37 → 0.80)** | **26.4분** | **34 kWh** |
| **실측 중앙** | **26.3분** | ? |

**26.4 vs 26.3.** 목표 SoC 를 쓸어 봐도 **0.80 이 가장 가깝다.**

| 목표 SoC | 0.70 | 0.75 | **0.80** | 0.85 |
|---|---:|---:|---:|---:|
| 분/세션 | 19.3 | 22.8 | **26.4** | 38.9 |

0.80 은 사람이 멈추는 자연스러운 지점이기도 하다 — 우리 곡선도 그 위에서
**164kW → 47kW 로 급락**한다.

#### 그리고 출력 둔감성도 이걸로 설명된다

150·200·350kW 어디서 계산해도 **26.4분으로 같다.** 저온계수 0.61 을 먹은 곡선
출력(최대 ~136kW)이 **충전기 정격보다 낮아서 배터리가 제한**하기 때문이다.

> **⚠ 내가 앞에서 "출력에 둔감하니 유휴다" 라고 한 것은 틀렸다.** 둔감성은
> 배터리 제한으로도 똑같이 나온다 — **두 설명을 가르지 못하는 증거**였다.
> 게다가 내가 쓴 묶음은 **휴게소 최대출력**이라, 그 세션이 실제로 받은 출력과 다르다.

#### 시간대 검정도 유휴 가설에 반대한다

| 구간 | 심야 0-5 | 점심 11-14 | 저녁 18-21 |
|---|---:|---:|---:|
| 실측 분/세션 | **29.7** | 27.1 | 26.8 |

밥 때가 길어야 하는데 **심야가 가장 길다.** "밥 먹느라" 는 맞지 않는다.

### ★★ 이건 #112 가 이미 찾은 것이다

`docs/charge_amount.md` 첫 줄 —

> *"우리 차들은 **목적지까지 갈 만큼만** 채우고 있었다 (종료 SoC 53%, 체류 9.5분).
> 사람처럼 **가득 채우게** 하니 체류가 2.4배가 되고, 이용률이 실측 33.5% 에 대해
> 31.6% 로 맞는다."*

그 기능이 `habit_soc` 다. **그런데 지금 모든 시나리오에서 `habit_soc: 0.0` 으로 꺼져
있다.** 팀원의 20개 UE 실행도 `habit_soc=0.0` 이었다 (PR 본문에 명시).

끈 이유는 **#113** 이다 — `habit_soc` 를 켜면 상한에서 점질량이 생겨 상행 균형이
진동한다 (종료 SoC 가 정확히 0.800 인 정차 85%).

    #112 가 원인을 찾았다 → habit_soc 를 만들었다 → #113 때문에 껐다
    → 끈 채로 #64 검증을 돌렸다 → -65.39% 가 나왔다

**−65.39% 는 새 발견이 아니라 `habit_soc` 를 끄고 돌린 결과다.**

### #64 가 새로 준 것 — **보정 목표**

#112 는 "가득 채우게" 까지는 갔지만 **어디까지가 '가득' 인지**를 실측으로 못 정했다.
워터의 이용률은 집계값이라 세션 길이를 직접 주지 않았다.

**이제 준다.**

| | 값 | 출처 |
|---|---:|---|
| 실측 세션 길이 | **26.3분** | 환경부 로그 11,405건 |
| 그걸 재현하는 목표 SoC | **0.80** | 우리 충전 곡선으로 역산 |
| 그때 세션당 에너지 | **34 kWh** | 같은 계산 |

> **이건 "임의로 맞추기" 가 아니다.** 숫자를 예쁘게 만들려고 모수를 움직이는 게 아니라,
> **독립적으로 측정된 세션 길이**에 맞추는 것이다. 그리고 **반증 가능하다** —
> 실측 세션당 kWh 가 34 근처가 아니면 이 설명은 틀린 것이다.

### ★ 그 반증 조건이 충족됐다 (2026-10-16, #136)

위 문단이 반증 조건을 **미리 등록**해 뒀다. 팀원의 #134 검증이 그 값을 실제로 쟀다.

| | 값 | 출처 |
|---|---:|---|
| 예측 (이 문단) | **34 kWh 근처** | 우리 곡선 역산 |
| **실측 세션당 충전량** | **22.093** (원본단위, 11,405건) | #136 §11.2 |

**34 는 실측의 1.54배다. "근처" 가 아니다.** 그러므로 **이 절이 스스로 정한
기준에 따라, `habit_soc=0.80` 이 점유시간 부족을 설명한다는 주장은 기각된다.**

#### 왜 34 가 나왔는가 — 그건 측정값이 아니었다

34 는 **"모두가 80%까지 충전하면 나올 양"** 이다. 우리 런의 평균 도착 SoC
0.3463 에서 0.80 까지면 Δ0.4537 이고, share 가중 평균 배터리 82.24kWh 를
곱하면 37kWh 가 나온다 (같은 종류의 계산, 역산 시점의 `soc_in` 에 따라 34~37).
**가정에서 나온 목표치를 실측과 나란히 적은 것이 잘못이었다.**

#### `26.3분` 의 라벨도 틀렸다

이 절은 26.3 을 **"실측 세션 길이"** 라고 적었다. 실제로는 **비교 가능한 25개소의
지점별 `점유분÷시작건수` 비율의 중앙값**이다 (#136 §8.5-2). 개별 세션 통계는
**중앙 26.667분 · 평균 27.117분** 이다. 숫자는 우연히 가깝지만 **다른 통계**다.

#### 그리고 충전량만으로는 시간이 안 맞는다

기본 base UE 40런·세션 86,133건에서 모델 쪽을 직접 쟀다
(`habit_soc=0.0` · `cap=0.8` · −5°C 확인):

| | 모델 | 실측 | |
|---|---:|---:|---|
| 세션 충전량 | 13.358 kWh | 22.093 | −39.5% |
| 세션 시간 | 9.60분 | 27.12분 | −64.6% |
| 실효 출력 | 83.50 kW | 48.88 | 모델 1.71배 |

**두 축이 같은 비율로 틀리지 않았다.** 실측만큼(22.093) 충전하게 고쳐도 모델
출력에서는 **15.88분**이고 실측은 27.12분이다 — **11.24분(실측 세션의 41.5%)이
충전량으로 설명되지 않는다.**

> 그래서 **`habit_soc` 하나로 점유시간을 메우는 설계가 틀렸다.** 앞뒤로 10분을
> 균일하게 얹어 본 실험이 이탈을 **51 → 1,340대(26배)** 로 터뜨린 것도 같은
> 이유다 — 잔여 11.2분과 크기는 비슷했지만, 이미 에너지가 부족한 모델 위에
> **모든 세션에 균일하게** 더했다.

#### 살아남은 것과 죽은 것

| | |
|---|---|
| ✅ **유지** | `habit_soc` 는 실재하는 기전이다. **−65.39% 가 그것을 끄고 돌린 결과**라는 진단도 유지된다 (위 흐름도) |

| ❌ **기각** | `0.80` 을 보정 목표로 삼는 것, 34 kWh 를 실측과 동일시한 표 |
| ❌ **기각** | 26.3 을 "실측 세션 길이" 라고 부르는 라벨 |

## 4. ★ 비ME 17,693건 — 출력 선호가 만든 수치일 가능성

### 우리 런에서 잰 메커니즘

UE 는 **고출력 충전기를 체계적으로 과선택한다** (상행 47기, 시드 3개 평균).

| 출력대 | 충전기 몫 | 선택 몫 | **과선택 배율** |
|---|---:|---:|---:|
| 50kW 이하 | 14.9% | 3.5% | **0.2×** |
| 100kW | 31.9% | 21.6% | 0.7× |
| 200kW대 | 25.5% | 33.5% | 1.3× |
| 350kW+ | 27.7% | 41.4% | **1.5×** |

**양 끝이 7.5배 차이**다. 합리적인 행동이다 — 출력이 높으면 체류가 짧고 비용이 낮다.

### 그래서 ME/NONME 비교가 오염될 수 있다

ME 95기 / NONME 120기인데 모델 세션은 ME 8,413 / NONME 17,693 이다.

    충전기 1기당   ME 89건   ·   NONME 147건   →  NONME 가 1.65배

충전기 수 차이(1.26배)로는 설명이 안 된다. 그리고 팀원 보고의 지점별 패턴이 정확히
이 모양이다 — **UP 안성 ME 6 / 전체 2,406**, UP 청주 ME 1 / 917, UP 양산 ME 0 / 310.
PR 본문도 안성의 **260kW 비ME 가상 충전기 선택 집중**과 `MAX_POWER_IDLE` 을 지목했다.

### ★ xlsx 로 판정했다 — 출력 기울기가 아니라 **승자독식**이다

시트 `15_35개소공급포함`(휴게소별 ME/비ME 충전기 수) + `03_휴게소별29`(휴게소별
ME/NONME 세션)으로 바로 계산했다.

    충전기 1기당 세션   ME 91.3   ·   NONME 224.0   →  **NONME 가 2.45배**

충전기 수로는 설명이 안 된다. 그런데 **휴게소 최대출력과의 상관은 −0.29** 로 약하다.
출력 기울기 가설은 **틀렸다.**

**진짜 모양은 승자독식이다.** ME·NONME 를 둘 다 가진 **15개 휴게소 전부**에서 한쪽이
세션을 거의 전부 가져간다.

| NONME 세션 몫 | 휴게소 수 |
|---|---:|
| 90% 이상 (NONME 독식) | **10곳** |
| 75~90% | 0곳 |
| **25~75% (분배)** | **0곳** |
| 10~25% | 4곳 |
| 10% 미만 (ME 독식) | 1곳 |

> **분배 구간이 0곳이다.** 충전기를 3:6, 4:5 로 나눠 가진 곳에서도 세션은 100:0 으로
> 간다. UE 가 휴게소 안에서 **가장 좋은 충전기 하나**를 고르기 때문이다
> (`MAX_POWER_IDLE`). 그 충전기가 어느 운영사 것이냐에 따라 전부 그쪽으로 간다.

### 그래서 ME 단독 비교가 무엇을 재고 있나

**환경부 실측 11,405건을 모델 ME 8,413건과 비교하는 것은, 휴게소마다 "가장 좋은
충전기를 어느 운영사가 가졌나" 에 좌우되는 수치와 비교하는 것이다.**

- 비ME 17,693 은 **수요 예측이 아니라 충전기 선택의 산물**이다
- ME −26.23% 도 수요 부족이 아니라 **라벨과 승자독식의 교락**이다
- 팀원이 PR 에 적은 *"모집단 정합성이 미확인된 조건부 진단"* 이 **정확히 맞았고,
  그 크기를 이제 알 수 있다**

> **우리 런에서 잰 메커니즘**: UE 는 350kW+ 를 충전기 몫의 **1.5배**, 50kW 이하를
> **0.2배** 선택한다 (양 끝 7.5배). 합리적 행동이지만, 운영사 라벨이 충전기에 붙어
> 있으면 **운영사별 비교를 무의미하게 만든다.**
