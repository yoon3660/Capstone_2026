- **말**: *"교통경제학의 고전적 구조입니다. 새로운 건 충전소 배정에 적용할 때

- 그림: 없음

## 6. ★ 왜 대기가 아니라 **종료시각**인가 — 1분

- **수식**
  ```
  MEC = Σ(내가 있을 때 남들의 충전 종료시각) − Σ(없을 때)
  ```
- **연쇄를 한 줄씩 보이기**
  ```
  내가 들어온다 → 충전기 배정이 바뀐다 → 그 차가 받는 출력이 바뀐다
               → 충전시간이 바뀐다 → 종료시각이 바뀐다
  ```
- **말**: *"대기만 세면 **출력이 바뀌어 충전이 길어진 몫**을 놓칩니다.
  이게 저희가 가져가는 기여의 핵심입니다"*
- 그림: 위 연쇄 화살표 ← **직접 그리기**
